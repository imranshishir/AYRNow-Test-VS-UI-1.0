Chapter 5

Tenant OS — First Time Onboarding + Lifecycle

Tenant Lifecycle: Invite → Verification → Lease → Living → History

Invite (SMS/Email/TID)
Verify (ID + selfie)
Lease (sign + docs)
Approve (landlord)
Move-in (date + rent)
Living (payments + maintenance + community)
History (statements + profile rating)

Invites

  • Landlord can invite using Tenant ID (TID), phone, or email.
  • If tenant has no invite, they can still create a profile and then use: Apply / Find your landlord / Property ID from dashboard.
  • Tenants are always welcome to create a “ready profile” with docs for fast application.

Verification (KYC-lite)

  • Upload government ID (front/back).
  • Take selfie photo inside app.
  • Optional: proof of income / residency docs.
  • Tenant profile generates a rating + verified badge over time.

Lease Signing

  • Tenant reviews agreement (PDF view) and signs digitally.
  • Tenant can upload additional addenda (pet, parking, custom lease rules).
  • Once signed, landlord finalizes: move-in date, rent, deposits, billing schedule.

After Move-in

  • Rent board + payment history + receipts.
  • Maintenance ticketing + status tracking.
  • Community posts (building-level) + landlord announcements.
  • End-of-year: tenant statement + hassle-free residency proof documents.
